## 🧠 What is SpashtAI?

**SpashtAI** *(Spasht — meaning "clear" in Hindi)* is a premium, AI-powered insurance intelligence platform built for the **Indian market**. Millions of Indians pay for policies they don't understand and only discover what isn't covered when they need it most — during a health crisis.

SpashtAI fixes this by reading every line of your policy PDF and delivering instant, plain-language clarity powered by **Google Gemini 2.5 Flash**.

### The Problem
> Hidden clauses. Confusing jargon. Unexpected out-of-pocket costs. Most people don't find out what their insurance actually covers until they're in the hospital.

### The Solution
> Upload your policy PDF → Gemini AI dissects every clause → You get a transparent breakdown of coverage, exclusions, personalized risks, and an actionable SpashtAI Score.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- **Node.js** ≥ 20.x — [Download](https://nodejs.org/)
- **npm** ≥ 10.x (comes with Node.js)
- **Git** — [Download](https://git-scm.com/)
- A **Google Firebase** project — [Create one](https://console.firebase.google.com/)
- A **Google Gemini API Key** — [Get one](https://ai.google.dev/)

---

### 1. Clone the Repository

```bash
git clone https://github.com/anshika-atulgupta/spashtAi.git
cd spashtAi
```

---

### 2. Install Dependencies

```bash
npm install
```

---

### 3. Set Up Environment Variables

Copy the example file and fill in your keys:

```bash
cp .env.example .env.local
```

Open `.env.local` and add your credentials:

```env
# ─── Firebase Client Config ───────────────────────────────────────
# Get these from Firebase Console → Project Settings → Your Apps → Web App
NEXT_PUBLIC_FIREBASE_API_KEY="AIza..."
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN="your-project.firebaseapp.com"
NEXT_PUBLIC_FIREBASE_PROJECT_ID="your-project-id"
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET="your-project.appspot.com"
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID="123456789"
NEXT_PUBLIC_FIREBASE_APP_ID="1:123456789:web:abc123"

# ─── Firebase Admin Config ────────────────────────────────────────
# Get these from Firebase Console → Project Settings → Service Accounts → Generate New Key
FIREBASE_PROJECT_ID="your-project-id"
FIREBASE_CLIENT_EMAIL="firebase-adminsdk-xxx@your-project.iam.gserviceaccount.com"
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"

# ─── Gemini AI ────────────────────────────────────────────────────
# Get from: https://ai.google.dev/ → Get API Key
GEMINI_API_KEY="AIza..."
```

> **Important:** The `FIREBASE_PRIVATE_KEY` value must be wrapped in double quotes and contain literal `\n` for newlines exactly as shown above.

---

### 4. Configure Firebase

#### Enable Authentication
1. Go to [Firebase Console](https://console.firebase.google.com/) → **Authentication** → **Sign-in method**
2. Enable **Google** as a sign-in provider
3. Add `http://localhost:3000` to the authorized domains

#### Enable Firestore
1. Go to **Firestore Database** → **Create Database**
2. Choose **Production mode** (rules are already in `firestore.rules`)
3. Select your preferred region (e.g., `asia-south1` for India)

#### Deploy Firestore Rules (Optional)
```bash
npx firebase deploy --only firestore:rules
```

---

### 5. Run the Development Server

```bash
npm run dev
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser. You should see the SpashtAI landing page.

---

### 6. Build for Production

```bash
npm run build
npm start
```

## 🤖 How the AI Works

SpashtAI uses **Google Gemini AI** via Server Actions — keeping your API key secure on the server and your PDF data never exposed to the client.

### Model Cascade (Automatic Failover)
When rate limits or quota errors occur, the system automatically tries models in order:

```
1. gemini-2.0-flash          (Primary — fastest, cost-effective)
2. gemini-2.5-flash-preview  (Secondary — highest capability)
3. gemini-1.5-pro            (Tertiary — reliable fallback)
4. gemini-2.0-flash-lite     (Final — lightweight fallback)
```

### AI Analysis Pipeline

```
User uploads PDF
      ↓
FileReader → base64 encode
      ↓
Server Action: analyzePolicy()
      ↓
Gemini receives: [PDF inline data + structured prompt]
      ↓
Returns JSON: {
  policyName, score, scoreBreakdown,
  coverage[], exclusions[], personalizedRisks[],
  keyFacts, improvements[], scoreReason
}
      ↓
Results saved to Firestore (users/{uid}/policyAnalyses)
      ↓
UI renders 3-column card layout
```

---

## 🔐 Security & Privacy

- **PDF files are never stored** — they're base64-encoded in memory, sent to Gemini for analysis, then discarded
- **Server Actions** protect your `GEMINI_API_KEY` — it never reaches the browser
- **Firestore Security Rules** ensure users can only read/write their own data
- **Firebase Auth** handles all authentication — no custom password storage
- Your personal profile data stays in your own Firebase instance

## 🎨 Design Philosophy

SpashtAI is built with a **premium dark-mode glassmorphism** aesthetic:

- **Color Palette:** Deep navy-black backgrounds (`#0e0e16`) with blue-to-purple gradients
- **Glassmorphism:** `backdrop-blur` + semi-transparent backgrounds + subtle borders
- **Ambient Glows:** Fixed-position blurred color blobs create depth and atmosphere
- **Micro-animations:** Framer Motion `whileInView` entry animations, spring transitions, hover scale effects
- **Typography:** System font stack with tight tracking for headings, relaxed for body

### Score Color System
```
Score ≥ 75  → Emerald green  (Great coverage)
Score ≥ 50  → Amber yellow   (Average coverage)
Score < 50  → Red/Rose       (Needs improvement)
```

### Category Colors
```
✅ Covered    → Emerald green  (#22c55e)
❌ Excluded   → Red            (#ef4444)
⚡ Risks      → Amber yellow   (#eab308)
```
